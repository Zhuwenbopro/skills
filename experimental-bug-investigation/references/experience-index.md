# 调查经验索引

经验条目只提供领域特定的假设、证据和实验捷径，不改变主流程的证据标准。仅在症状匹配时加载对应条目；未匹配时不要加载，以免用历史案例替代当前证据。

| 症状/关键词 | 经验条目 | 用途 |
|---|---|---|
| SGLang、HTTP 400、Bad Request、OpenAI-compatible API、请求校验、Chat template | [SGLang HTTP 400](./sglang-http-400.md) | 收集 HTTP 交换，按 schema、长度、采样、模板、grammar、speculative 和 gateway 分层做实验 |

## 使用规则

1. 先记录当前案例和失败谓词，再查索引。
2. 经验只能生成候选假设和实验，不能直接成为当前案例的根因。
3. 当前响应体、日志和 A/B 实验与经验冲突时，以当前证据为准。
4. 新经验必须可复用，至少包含：适用症状、最少证据、假设类别、低成本实验顺序和结论边界。
5. 不把单次案例的模型路径、端口、PID、时间或未经验证的结论写入经验库；这些内容留在案例报告。
6. 相近经验应合并，避免主 Skill 或索引膨胀为故障清单。
